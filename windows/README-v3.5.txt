OpenQQ QQ 同步桥 v3.5（Windows）

本版本在 v3.4 多官bot并发修复之上，补上三处被回退/遗漏的健壮性问题。

============================================================
一、v3.5 修了什么
============================================================

【1】恢复「首次快照」生成（v3.4.1 遗漏）

  现象：增量同步路径从不产生 .snapshot-first.bak，只有会被滚动清理的临时备份，
        一旦需要回滚就没有长期基线可用。

  修复：_rolling_backup 首次备份时同时写下永不覆盖的首次快照。

【2】data.db 与 data-logs.db 相互独立（v3.4.1 回退）

  现象：缺少或损坏 data-logs.db 时整轮同步失败，连角色卡和 PC 数据也一起不更新。

  修复：connect() 只校验实际打开的那个文件；日志同步失败则记录日志后继续。

【3】备份失败不再阻断同步（v3.4.1 回退）

  现象：磁盘临时不可写导致备份抛异常时，所有群的同步一起停摆。

  修复：备份异常记入 bridge_error.log 后继续同步。

【4】加固兜底覆盖的原子性（本版新增）

  3.4.1 的 _commit_file 在重试仍失败时会直接截断覆盖目标文件，
  若进程正好在写一半时被杀，配置文件会变成半个 JSON，等于绑定记录全丢。

  修复：兜底改为「先备份 -> 写临时文件 -> 校验字节数 -> 失败回滚」。

============================================================
二、怎么更新
============================================================

双击「更新OpenQQ同步桥-v3.5.cmd」，自动下载、备份、替换。

手动：
  1. 关掉正在运行的旧桥
  2. 用 OpenQQ-QQ-Sync-Bridge-v3.5.exe 替换旧 exe
  3. 把 OpenQQ-QQ-Sync-v3.5.js 放进海豹 data/default/scripts，
     旧的 v3.4 js 改名加 .disabled 或删除
  4. 用「启动OpenQQ同步桥-v3.5.cmd」启动，再到 WebUI 重载插件

============================================================
三、兼容性
============================================================

与 v3.4 / v3.4.1 / v3.3 数据完全兼容：绑定记录和同步队列都保留，
bridge_port.txt、bridge_bindings.json、sync_config.json 原地沿用。
