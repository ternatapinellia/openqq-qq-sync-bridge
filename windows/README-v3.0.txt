==============================================================
  OpenQQ QQ Sync Bridge v3.0
==============================================================

旧 QQ → OpenQQ 数据迁移同步桥

作用：把旧 QQ 的角色卡、PC 数据、log 搬到你的 OpenQQ 账号。

完整使用说明请看：
    README-WINDOWS.txt


--------------------------------------------------------------
快速开始（Windows）
--------------------------------------------------------------

1. 把这三个文件放到海豹主程序目录（和 data 文件夹平级）：
       OpenQQ-QQ-Sync-Bridge-v3.0.exe
       启动OpenQQ同步桥-v3.0.cmd
       bridge_port.txt

2. 把 OpenQQ-QQ-Sync-v3.0.js 放进海豹的 js 插件目录，重载插件。

3. 双击 启动OpenQQ同步桥-v3.0.cmd，黑窗口保持开着。

4. 插件配置里填好发件邮箱和 SMTP授权码，
   先执行 .旧QQ邮箱测试 确认能收到邮件。

5. 在群里执行：
       .旧QQ绑定 <旧QQ号> <旧群号>
       .旧QQ验证码 <6位验证码>
