OpenQQ 同步桥 v3.4 更新说明
==================================================

【适用于 Windows】

把下面这些文件放到同一个文件夹（通常就是海豹主程序目录）：
    OpenQQ-QQ-Sync-Bridge-v3.4.exe
    OpenQQ-QQ-Sync-v3.4.js
    启动OpenQQ同步桥-v3.4.cmd
    更新OpenQQ同步桥-v3.4.cmd

然后双击「更新OpenQQ同步桥-v3.4.cmd」。

它会：
  1. 自动结束正在运行的旧桥（会先问你）
  2. 从网站或 GitHub 下载 3.4 发布包
  3. 把旧文件备份到 backup-<日期> 目录
  4. 替换 exe、插件、启动脚本

更新完成后：
  1. 双击「启动OpenQQ同步桥-v3.4.cmd」重新启动桥
  2. 把 OpenQQ-QQ-Sync-v3.4.js 放进海豹 data/default/scripts
     并把旧的 v3.3 js 删除或改名加 .disabled
  3. 在 WebUI 里重载插件

【适用于 Linux / Docker】

sh ./更新OpenQQ同步桥-v3.4.sh [部署目录]

不加参数就在当前目录执行。它会备份、替换 bridge.py 与插件，
并在有 docker compose 时自动重建容器。

==================================================
v3.4 主要修复
==================================================

1. 多官bot并发时，同步队列会被覆盖，导致「绑定了却不同步」
2. sync_config.json 并发写入报错，并留下 .tmp 垃圾文件
3. 每轮同步都做全量快照，多官bot时磁盘 IO 过高
