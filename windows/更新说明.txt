OpenQQ 同步桥 v3.5 更新说明
==================================================

【Windows】
把 exe / js / 两个 cmd / README 放在同一文件夹，
双击「更新OpenQQ同步桥-v3.5.cmd」。
它会先结束旧桥，再下载、备份、替换。
更新后重启桥，并在 WebUI 重载插件。

【Linux / Docker】
sh ./更新OpenQQ同步桥-v3.5.sh [部署目录]
不加参数就在当前目录执行。

==================================================
v3.5 主要修复
==================================================

1. 恢复首次快照生成（v3.4.1 遗漏）
2. data.db 与 data-logs.db 独立：缺一个不再连累另一个
3. 备份失败不再阻断同步
4. 兜底覆盖改为两段式，避免半个 JSON 导致绑定记录全丢
