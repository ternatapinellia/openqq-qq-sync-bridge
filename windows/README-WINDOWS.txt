==============================================================
  OpenQQ QQ Sync Bridge —— Windows 版使用说明
==============================================================

把旧 QQ 的角色卡、群属性、log 迁移到 OpenQQ 账号。
双击即用，不用装 Python，不用装 Docker。


--------------------------------------------------------------
一、一共要放三样东西
--------------------------------------------------------------

  放在哪里                        放什么
  ----------------------------------------------------------
  海豹主程序目录                   OpenQQ-QQ-Sync-Bridge-v3.0.exe
  （和 data/ 平行）                启动OpenQQ同步桥-v3.0.cmd
                                  bridge_port.txt

  海豹的 js 插件目录               OpenQQ-QQ-Sync-v3.0.js

  海豹插件的配置界面               邮箱、SMTP 授权码（见第三节）


放好之后目录长这样：

  Sealdice/
  |- Sealdice.exe
  |- data/
  |  \- default/
  |     |- data.db          <- 海豹的数据库，同步桥会读它
  |     \- data-logs.db
  |- OpenQQ-QQ-Sync-Bridge-v3.0.exe     <- 放这里
  |- 启动OpenQQ同步桥-v3.0.cmd           <- 放这里
  |- bridge_port.txt                    <- 放这里（内容默认 38999）
  \- ...

  注意：这三个文件必须待在【同一个文件夹】里。同步桥是以 exe 所在目录
        为工作根目录去寻找 data/default 的。


--------------------------------------------------------------
二、启动同步桥
--------------------------------------------------------------

双击 启动OpenQQ同步桥-v3.0.cmd，会弹出一个黑色窗口，出现这些内容就是成功了：

  OpenQQ QQ Sync Bridge v3.0
  Listening: 127.0.0.1:38999
  Data dir: D:\Sealdice\data\default
  Config dir: D:\Sealdice
  Token required: no

  【这个窗口要一直开着，不能关。】
  关了就等于同步桥停了，之后海豹里的指令会报“无法连接同步桥”。

第一次启动可能会弹 Windows 防火墙提示。因为同步桥只监听 127.0.0.1
（本机），点“取消”即可，不需要放行。


--------------------------------------------------------------
三、在海豹里配置插件
--------------------------------------------------------------

加载 OpenQQ-QQ-Sync-v3.0.js 后，在插件配置界面填这几项：

  发件邮箱      ： 你的 QQ 邮箱，如 123456@qq.com
  SMTP授权码    ： QQ 邮箱的 SMTP 授权码（不是 QQ 登录密码！见下面）
  SMTP服务器    ： smtp.qq.com（默认值，一般不用改）
  SMTP端口      ： 465（默认值，一般不用改）
  Bridge端口    ： 38999（必须和 bridge_port.txt 里的数字一致）
  Bridge主机    ： 127.0.0.1（Windows 本机用默认值，不用改）
  Bridge访问令牌： 留空（Windows 本机用不需要令牌）


SMTP 授权码怎么拿：

  1. 登录 QQ 邮箱网页版 → 设置 → 账号
  2. 找到“POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV服务”
  3. 开启 SMTP 服务，按提示用手机发短信验证
  4. 拿到一串 16 位的授权码，填到“SMTP授权码”里

填完先执行一次 .旧QQ邮箱测试，收到测试邮件就说明配好了。
收不到先看第八节。


--------------------------------------------------------------
四、执行迁移
--------------------------------------------------------------

全部指令都在【目标群】（也就是你现在用的 OpenQQ 群）里执行。

第 1 步，申请验证码：

  .旧QQ绑定 <旧QQ号> <旧群号>

  例如：.旧QQ绑定 2522629086 1081354778
  执行后，系统会给 2522629086@qq.com 发一封带 6 位验证码的邮件。

第 2 步，去旧 QQ 邮箱收验证码：

  验证码 5 分钟内有效，超时要重新申请。

第 3 步，提交验证码完成迁移：

  .旧QQ验证码 123456

  验证通过后立即开始迁移，并把结果显示出来，大致是：

    同步完成！

    角色卡：3 张
    - 罗京立
    - 藤本千夏
    - 沃米尔

    群属性：1 条
    Log：5 个
    Log记录：4506 条

  看到这个就成功了。接下来 .st、.pc、.log 这些指令就能看到
  迁移过来的东西了。


--------------------------------------------------------------
五、全部指令一览
--------------------------------------------------------------

  .旧QQ绑定 <旧QQ> <旧群>    申请验证码（往旧QQ邮箱发信）
  .旧QQ验证码 <6位数字>      提交验证码，验证通过后开始迁移
  .旧QQ邮箱测试              往配置的发件邮箱发一封测试邮件
  .旧QQ桥状态                检查同步桥是否正常，显示端口和版本
  .旧QQ角色 [旧QQ]           查看该旧 QQ 有哪些角色卡
  .旧QQ绑定信息              查看当前群绑定了哪个旧 QQ / 旧群
  .旧QQ解绑                  解除当前群的绑定

  <尖括号> 表示要替换的内容，实际输入时不要带尖括号。


--------------------------------------------------------------
六、几个重要规则
--------------------------------------------------------------

1. 迁移只做一次。
   验证码通过的那一刻把旧数据复制过来，之后就结束了。旧群后来产生的
   新日志不会自动跟过来，两边数据各自独立。

2. 一个旧 QQ + 旧群只能绑一次。
   已经绑定过的组合，再想绑到别的 OpenQQ 账号会被拒绝（这是防误绑）。
   要改绑先执行 .旧QQ解绑。

3. 验证码限制：
   5 分钟有效，最多输错 5 次，超了要重新申请。


--------------------------------------------------------------
七、迁移前会自动备份
--------------------------------------------------------------

迁移前，同步桥会在 data/default/ 里自动备份，角色卡库和日志库
【各自独立备份】，互不影响：

  data.db.snapshot-first.bak         角色卡库的首次快照，永久保留，
                                     不会被覆盖或删除
  data-logs.db.snapshot-first.bak    日志库的首次快照，同样永久保留
  data.db.before-sync-<时间>.bak     最近 2 份滚动备份，多的自动清理
  data-logs.db.before-sync-<时间>.bak  同上


出问题了想还原，用 .snapshot-first.bak 最稳妥。还原步骤：

  1. 先关掉海豹和同步桥
  2. 删掉同名的 -wal 和 -shm 文件（如果有）
  3. 把 .snapshot-first.bak 改名回去替换 data.db（或 data-logs.db）
  4. 重新启动海豹


--------------------------------------------------------------
八、常见问题
--------------------------------------------------------------

双击 cmd，窗口一闪就没了
  OpenQQ-QQ-Sync-Bridge-v3.0.exe 和 bridge_port.txt 是不是没和 cmd
  放在一起？三个文件必须在同一个文件夹里。

插件报“无法连接同步桥 38999”
  按顺序检查：
    1. cmd 那个黑窗口是不是被关了？
    2. bridge_port.txt 里的数字，和插件里填的“Bridge端口”是否一致？
    3. 38999 端口是不是被别的程序占了？可以把 bridge_port.txt 改成
       39000，插件里也改成 39000，然后重启 cmd。

收不到验证码邮件
  先执行 .旧QQ邮箱测试。收不到一般是这三个原因：
    1. “SMTP授权码”填成了 QQ 登录密码（必须是那串 16 位授权码）
    2. QQ 邮箱的 SMTP 服务没开启
    3. 邮件进了垃圾箱

提示“该旧QQ与该旧群都没有找到可迁移的数据”
  说明旧 QQ 在这个旧群里既没有角色卡，也没有 log。检查旧群号填对了没有。

提示“该旧QQ/旧群已经绑定到其他OpenQQ账号或群”
  这个组合之前绑过了。确认要重新绑的话，先执行 .旧QQ解绑。

结果显示“Log迁移失败 N 个”，但其他都好了
  不用担心，失败的那几条会被跳过，其余照常迁移，【不会整批失败】。
  具体是哪几条、什么原因，看同步桥目录下的 bridge_error.log。

结果显示“识别为已迁移、未重复复制”
  说明这次执行时这些 log 之前已经迁移过了，自动跳过避免重复，
  属于正常情况。

旧群里的 log 名字和我这边的重名了怎么办
  会自动改名为“原名 (2)”、“原名 (3)”，内容都保留，不会丢。


--------------------------------------------------------------
九、文件说明
--------------------------------------------------------------

启动后目录里可能出现的文件：

  bridge_port.txt          同步桥端口，默认 38999
  bridge_bindings.json     记录绑定关系，防止误绑
  bridge_error.log         迁移失败详情（只在有失败时生成）
  data.db.snapshot-first.bak 等   迁移前的自动备份


--------------------------------------------------------------
十、安全说明
--------------------------------------------------------------

  * 同步桥只读写【本机】的海豹 sqlite 文件，不会把数据上传到任何地方。
  * 只监听 127.0.0.1，局域网内其他机器访问不到。
  * 验证码邮件是通过【你自己配置的】SMTP 邮箱发出的，不经过第三方服务器。
