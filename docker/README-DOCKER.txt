==============================================================
  OpenQQ QQ Sync Bridge v3.0 —— Linux 版使用说明
==============================================================

这里教的只有一件事：在 Linux 服务器上把同步桥跑起来，
让海豹能连上它。

全程只需要做 4 步，一步步来就行。


--------------------------------------------------------------
第 1 步：把 docker 文件夹传上服务器
--------------------------------------------------------------

把电脑上的 docker 这个文件夹，整个传到服务器任意位置，
比如 /root/openqq-bridge。

（用 FinalShell / WinSCP / 宝塔面板，直接拖上去就行）


--------------------------------------------------------------
第 2 步：找到海豹的数据文件夹
--------------------------------------------------------------

海豹的数据在它自己的目录里，路径一般是：

    /xxx/Sealdice/data/default

这个文件夹里应该有这两个文件：

    data.db
    data-logs.db

把它的完整路径记下来，等会儿要填。
（在宝塔/FinalShell 里点进文件夹，复制上面的路径）


--------------------------------------------------------------
第 3 步：改一个配置文件
--------------------------------------------------------------

在服务器上打开 docker 文件夹里的 .env.example，
先把它复制一份，改名成 .env，然后改两行：

    SEALDICE_DATA_DIR=/xxx/Sealdice/data/default
    OPENQQ_BRIDGE_TOKEN=随便打一串字母数字

例如：

    SEALDICE_DATA_DIR=/opt/Sealdice/data/default
    OPENQQ_BRIDGE_TOKEN=abc123def456

两个说明：
  * SEALDICE_DATA_DIR 就是第 2 步记下的路径，要写完整。
  * OPENQQ_BRIDGE_TOKEN 是自己随便定的密码，
    后面在海豹插件里要填一样的内容。


--------------------------------------------------------------
第 4 步：启动
--------------------------------------------------------------

在服务器的命令行里，进入 docker 文件夹，执行：

    docker compose up -d

第一次会下载和构建，等一两分钟。

看到这行就成功了：

    Started

然后检查一下：

    curl http://127.0.0.1:38999/health

如果返回

    {"ok": true, "version": "3.0", ...}

就说明跑起来了。


--------------------------------------------------------------
海豹那边怎么填
--------------------------------------------------------------

海豹插件里只填三项：

    Bridge主机    ： 127.0.0.1
    Bridge端口    ： 38999
    Bridge访问令牌： 第 3 步自己定的那串

然后原样执行迁移：

    .旧QQ绑定 <旧QQ> <旧群>
    .旧QQ验证码 <6位数字>

和 Windows 版完全一样。


--------------------------------------------------------------
出问题先看这三条
--------------------------------------------------------------

1) 怎么知道有没有在跑

    docker compose ps

   看到 running 就是好的。

2) 起不来 / 说找不到 data.db

   说明第 3 步的 SEALDICE_DATA_DIR 路径写错了。
   复制你第 2 步记下的路径直接粘，别手打。

3) 海豹说连不上

   先在服务器上执行：

    curl http://127.0.0.1:38999/health

   这条都通不了，就是桥没起来；通了但海豹还是连不上，
   就检查插件里的 主机 / 端口 / 令牌 这三项有没有对上。


--------------------------------------------------------------
想停掉 / 想重启
--------------------------------------------------------------

    停止： docker compose down
    重启： docker compose restart
    看日志： docker compose logs -f

停止不会删数据，海豹的东西还在你自己的文件夹里。


--------------------------------------------------------------
顺便说一句
--------------------------------------------------------------

* 迁移前会自动备份，备份就放在海豹的 data/default 里，
  文件名带 .bak。出问题可以用它还原。
* 迁移只做一次，之后旧群的新消息不会自动同步。
* 全程只有你自己服务器上的文件在动，不会上传到别的地方。
